## 修复 run.sh 的 .well-known 丢失 bug

- 现象：`run.sh` 启动后 Chrome 请求 `/.well-known/appspecific/com.chrome.devtools.json` 报 404 ERROR（Chrome DevTools 自动工作区探测，无害但刷屏）
- 根因：`tools/run.sh` 的 `_init()` 用 `cp -r ./*` 拷贝工作区到 .container，**glob 不匹配点目录**，.git 有单独补拷但 .well-known 没有
- 修复：run.sh 增加 `cp -r ./.well-known "$CONTAINER"`（带存在性判断）；直接 `jekyll build` 本来就正常（_config.yml 的 include: [.well-known] 有效）
- 用户已提前创建好 JSON 文件（内容 `{}`）和 include 配置，只差 run.sh 这一步

## 修复图片灯箱 aria-hidden 警告

- 现象：点击文章图片放大时 Chrome 警告 "Blocked aria-hidden on an element because its descendant retained focus"（焦点元素 `<a.popup>` 在被 aria-hidden 的 `#main-wrapper` 内）
- 根因：glightbox 打开时给页面容器加 aria-hidden，但不移除触发链接的焦点（glightbox 已知无障碍问题）
- 修复：`_includes/image-preview.html` 增加捕获阶段 click 监听，点击 `.popup` 链接时立即 blur——capture 保证在 glightbox 自己的 handler 之前执行
- 挂载点：post.html / page.html 两处 include，构建产物已验证包含修复代码
